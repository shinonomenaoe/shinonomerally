
Thank you for purchasing EasyRoads3D Pro

This package includes the EasyRoads3D Pro tool and the basic demo scene.

The manual is located in the EasyRoads3D root directory. The first Quick Start page includes video tutorials: https://www.easyroads3d.com/v3/html/quick_start.html 
The general workflow is explained here: https://www.easyroads3d.com/v3/html/general_workflow.html

To get familiar with the tool you can also download the free demo project: https://assetstore.unity.com/packages/tools/terrain/easyroads3d-demo-project-105045

It is recommended to look at these reources before starting to use the asset in your projects, especially the Getting Started video. It helps becoming familiar with the tool and get the most out of it. 

The mentioned Demo package Project includes a wide range of additional road type and side object assets. It is recommended to import this package in a new project first. But it can also be imported in your project 
if you want to use all assets. Otherwise assets can be exported from the other project and imported in your own projects. 

The road types and side objects in the demo project can be used in your own personal and commercial projects except for asset store packages. 
Please contact us for permission to use these assets in Unity asset store packages or for example open source Unity projects.
