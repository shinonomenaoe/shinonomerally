EasyRoads3D V3 Manual
 

 

Getting Started

 

IMPORTANT: always check the Release Notes section for important information!

Download Files From www.easyroads3d.com

The zip file contains the following items:

1. EasyRoads3D.unityPackage
2. Manual
3. licence

 

Download and Import the EasyRoads3D packages from the Unity Asset Store

EasyRoads3D FREE: https://assetstore.unity.com/packages/3d/characters/easyroads3d-free-v3-987

EasyRoads3D Pro: https://assetstore.unity.com/packages/tools/terrain/easyroads3d-pro-v3-469

The free (if you have a Pro license) additional demo package: https://assetstore.unity.com/packages/tools/terrain/easyroads3d-demo-project-105045

Download and import the EasyRoads3D packages from the Unity Package Manager

All necessary assets will be imported in your project. A new menu item EasyRoads3D will be available in the top menu. Click on an empty area in the top menu bar if the EasyRoads3D menu item is not visible.

 

URP & HDRP

After the EasyRoads3D package is imported from the Unity Asset Store, the currently active render pipeline of the project is detected. You will be asked to confirm the import of the URP or HDRP material package that matches the Unity version and the active render pipeline in the current project.

If this automated material and shader package import fails and in the case road network materials are still purple, you can manually import the package that matches your current RP version—or the closest previous version—from this location.

/Assets/EasyRoads3D/SRP Support Packages/

 

Create a new road network

After importing the package the following new menu item will be added to the main menu in the Unity Editor:

Main Menu > GameObject > 3D Object > EasyRoads3D > New Road Network

A new game object "Road Network" will be created in the scene hierarchy. It will be auto selected and the EasyRoads3D v3 toolbar will appear in the Inspector
